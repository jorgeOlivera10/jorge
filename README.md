# Biwenger Analyzer

Herramienta de análisis y automatización para mi liga de **Biwenger** (fantasy de LaLiga):
ingesta diaria de datos, reconstrucción de la economía de cada rival, detección de
chollos, scouting de jugadores y un dashboard con actualización automática.

👉 **El proyecto está en la carpeta [`biwenger/`](biwenger/).** Consulta
[`biwenger/README.md`](biwenger/README.md) para el setup, los comandos de la CLI y el
despliegue del dashboard.

El dashboard diario se publica automáticamente vía GitHub Actions + GitHub Pages.
